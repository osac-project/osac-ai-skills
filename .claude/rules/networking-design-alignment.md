# Networking Design Alignment

When working on networking-related tasks (Connectivity&Fabric component, networking resources like VirtualNetwork/Subnet/SecurityGroup/ExternalIP/NATGateway/NetworkClass, NICs, ports, interfaces, network attachments, VLANs, fabric/K8s managers, dispatcher, MetalLB, DNS, CIDR, DNAT/SNAT, peering, metering/QoS, IP address, MAC address, DHCP), read `.design/context/networking-decisions.md` before planning, implementing, or reviewing. For deep context, read the full designs linked from that file. This applies even when the task is framed as inventory/metadata exposure rather than networking explicitly — IP and MAC address for any provisioned resource are owned by the networking decisions in that file.
